## What this release contains

The source is `main` at `1fb5d01` plus uncommitted work: the Music upgrade and player bubble (0.1.23–0.1.25), the WorkManager start-up fix (0.1.26), the version bump, and the 2026-09-26 advertising changes. **Commit the source before uploading**, so that the bundle can be traced to a commit.

Changed since 0.1.26 (details in [mobile-admob-integration.md](../mobile-admob-integration.md)):

- Every Google native advert is drawn at the medium template's real 350dp height; the old 300dp box clipped the call-to-action.
- Every template text colour is set explicitly, so the advert's body text is legible in dark mode; it was white on white before.
- An "ADVERTISEMENT" label frames each Google advert. Space is held while a request is out, so a late advert never pushes content under a finger.
- One request per advert slot; a race on parent rebuilds could create two. Loaded adverts survive scrolling in lists. After an empty result, a placement waits 60 seconds before asking again.
- The Collection overview's advert is no longer a page of the auto-advancing story carousel; it is one stationary row under the channel grid, and takes no space when empty.
- If consent gathering fails, the app asks UMP whether stored consent still permits a request, as Google's guide says to. It never assumes consent.
- The production *profile* build type now uses Google's sample app id. This does not affect this release bundle.
