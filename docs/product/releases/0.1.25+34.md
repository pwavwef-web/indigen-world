## What this release contains

This is a new version of the Music upgrade described in [`0.1.24+33.md`](0.1.24+33.md). The mobile Dart source did not change between the two local bundles. Versions 0.1.23 (32) and 0.1.24 (33) were built locally but not uploaded, so this bundle includes their player bubble, Kasem contribution context, advertising fallback, and redesigned Music experience. The community announcement draft is `apps/updates-blog/posts/2026-09-24-music-reimagined/`.

The source is `main` at `1fb5d01` plus the existing uncommitted mobile changes, the version bump to `0.1.25+34`, and a release build fix in `android/app/build.gradle.kts`. The first 0.1.25 build failed because Flutter regenerated a Java plugin registrant containing the dev-only `integration_test` plugin. The Gradle production Java compile now removes that generated registration just before compiling. The successful second build used that fix; the app's Dart behavior was not changed. Commit the source before upload so the bundle can be traced to a commit.

## Checks and availability

- The successful build reports `0.1.25 (34)` in its merged manifest and `jar verified` for the bundle.
- The release signing certificate matches the previously verified 0.1.24 bundle.
- Before this version-only rebuild, `dart analyze lib test` was clean and the Music, shared, Collection and app tests passed (170 tests). The full suite had 1507 passing tests; one reel-editor test timed out under load and passed alone, as recorded in the 0.1.24 note. These tests were not repeated for the version bump and build fix.
- No physical phone test was done before the 0.1.25 build. A user later reported that Google Play installed this version and that it closes at the system splash screen. The preserved bundle reproduces that failure in an emulator: AndroidX Startup cannot create WorkManager's `WorkDatabase` because R8 removed `WorkDatabase_Impl`'s public no-argument constructor. Do not roll out this bundle further; the 0.1.26 fix is being prepared.
