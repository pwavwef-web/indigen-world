# Project Kassena: Kasem Language Cell

Project Kassena is Indigen World’s flagship Kasem-language programme and the first implementation of the reusable language-cell model.

## Scope

- Kasem lexical entries and English–Kasem mappings
- Contextual sentence pairs
- Dialect and regional variants
- Parts of speech and linguistic metadata
- Proverbs, idioms, stories, and oral histories under appropriate permissions
- Contributor, validator, review, consent, licence, and reward records
- Future approved audio-text pairs, ASR, TTS, and model-evaluation assets

## Quality requirements

The next data milestone is [one question-and-evidence cycle](person-meaning-pilot/README.md): documentary inspection, natural speech, scoped reconciliation, reviewed records and unseen Kawuri tests. Complete that pilot before expanding collection or preparing a training run. Its local tooling and targets do not imply a completed study or a live release.

- Raw submissions remain separate from approved production content.
- Every promoted entry records validation status and validator reference.
- Dialect variants are preserved rather than overwritten into one supposedly universal form.
- Linguistic changes require review by qualified Kasem validators.
- Cultural expressions require the relevant permission tier and attribution.
- AI-training eligibility is recorded separately from public-display permission.

## Repository restriction

Do not commit the production Kasem corpus, private contributor data, raw consent records, or restricted cultural content. This directory holds specifications, schemas, synthetic examples, approved public samples, and migration documentation only.
