`indigen-world-mark.png` is an exact raster rendering of the repository's
existing `apps/website/public/favicon.svg`, generated locally with its existing
resvg dependency at 192 px. It preserves the roof, three bars and sun geometry
and colors. It is used for verified Indigen house placements, not as a substitute
identity for other advertisers. The matching website asset lives in
`apps/website/public/brand/`.
