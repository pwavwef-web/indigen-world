# App typography

Noto Sans Regular and Bold are the existing repository fonts from
`services/functions/assets/fonts/`, bundled here so Kasem and app controls use
the same metrics offline on every supported phone. SIL Open Font License 1.1;
see OFL.txt. Original source: notofonts/noto-fonts, hinted/ttf/NotoSans. No font
was fetched as part of this update.
