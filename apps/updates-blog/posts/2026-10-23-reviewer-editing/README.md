## Publishing handoff

1. Confirm deployment and update the availability paragraph in `post.html` before describing this as live.
2. Create the Blogger post using the title, labels and search description above.
3. Upload `images/cover.png`, `images/admin-desktop.jpg`, `images/validator-desktop.jpg` and `images/validator-mobile.jpg` to Blogger.
4. Paste `post.html` in HTML mode. Replace each local image `src` with its uploaded Blogger URL, retaining alt text and captions.
5. Preview desktop and mobile, then publish when ready.
6. Replace the marked article-URL placeholder in `share.md` before sharing.

## Evidence and limits

See `docs/architecture/reviewer-editing.md` for the API, security and verification
commands. The new integration tests cover corrected public records, receipt
consistency, original credit/consent, audit history, role/MFA restrictions,
self-review rejection, closed states, failed atomic publication and concurrent
editing. Browser checks exercise real editing controls, save-and-continue and
combined publication payloads at desktop and phone widths with synthetic service
data. Test results are recorded in `verification.md`.

The feature edits existing submission content. It does not replace uploaded
files, grant publication permission, change contributor identity, or add/remove
structured dictionary meanings. Source-document material review remains its own
workflow. Preparing this article does not publish it, send an announcement or
deploy the application.
