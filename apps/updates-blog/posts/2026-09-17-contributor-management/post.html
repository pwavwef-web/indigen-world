Contributor work now has one administrative home. The new Contributors workspace brings profiles, invitations, expression assignments, reviews and contribution history together inside the Indigen World Admin console.

Find the person, then see the whole relationship

Authorized administrators can search the directory by name or email and narrow it by status, role, location or contribution type. Each record keeps public biography details separate from private contact information and internal editorial notes. Profile changes can be previewed before they are saved or made public.

A contributor can also have a profile without a login account. That makes it possible to preserve community relationships and accurate credits without forcing everyone into an online workflow.

Send real expression assignments

From the same directory, an administrator can invite a contributor with their first set of English expressions or allocate another set to an existing account. Each assignment can include a title, deadline and instructions, and its progress is visible from draft through submission and verification.

The system creates a private activation link for a new contributor. Administrators can copy it into an approved communication channel, create an email draft, issue a fresh link or cancel an invitation that has not been accepted. Automatic outbound email is not part of this release.

Review without losing the history

Submitted Kasem translations appear in a focused review table. Reviewers can approve them, request revisions with feedback, reject them, and publish approved work through the existing protected review workflow. Each contributor record also shows the work already associated with that person.

Contributor status, login access and public profile visibility are separate controls. Suspending or deactivating an account does not delete assignments, published contributions or attribution. Profile, permission, invitation, assignment, access and review decisions leave an audit record showing who acted and when.

First-release scope

This release covers the contributor directory, profile management, invitations, roles and permissions, activation and deactivation, expression allocation, submission review, contribution history and audit logging. Payments, agreement uploads, application intake, automatic email delivery and permanent deletion remain outside this first release.

Availability: implemented in the repository. Production availability must be confirmed after the Admin and Functions deployment and smoke test.
