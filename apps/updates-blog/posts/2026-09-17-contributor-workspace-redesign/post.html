Kasem expression assignments now have a more focused contributor experience. The redesigned workspace helps invited contributors choose an expression, translate it, add another natural phrasing when useful, and move directly to the next task.

Less scrolling, more translating

The contributor header, assignment details, guidance and progress are now compact. Search and status filters stay close to the expression list, while clear badges distinguish work that is not started, saved as a draft, submitted, uncertain or returned for revision.

A translation editor built for phones

The Kasem translation field appears first and the special-character keyboard stays within easy reach. Alternative phrasings are added one at a time instead of being entered in one large box. On phones, a sticky action area keeps Save draft and Submit & next available. Larger screens use a split view so contributors can move through the list without repeatedly leaving the editor.

Consent and provenance remain intact

This is an interface redesign, not a change to the contribution pipeline. Draft and submitted data remain distinct. Assignment IDs, contributor attribution, timestamps, review status and structured alternatives continue through the existing workflow. Publication permission keeps its existing meaning, and permission to use an approved translation for Kawuri AI training remains explicitly optional and off by default.

Helpful states when work is interrupted

Autosave still protects drafts and shows whether work is saving, saved or needs a retry. Contributors can recover an unsaved device copy, mark uncertain work without submitting it, see reviewer notes before revising, and receive a restrained completion message after submitting the assignment.

Availability

The redesign has passed local type checks, production build checks and the existing contributor workflow tests. Production deployment and an authenticated device-width smoke test are still pending, so this article should be published only after those checks are complete.
