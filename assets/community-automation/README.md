# Community automation artwork

Created 2026-10-02 using the built-in OpenAI imagegen tool. Each account has an original avatar.png and cover.png. These are illustrated account identities; the architecture motif is illustrative, not a documentary photograph. No external photograph was reused.

The daily word card is rendered separately in code using the exact published dictionary spelling and English meaning. Its Noto Sans font and SIL Open Font License are bundled under services/functions/assets/fonts/.
