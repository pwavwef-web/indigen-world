# Indigen World — 50 desktop wallpapers

Original AI-generated illustrations inspired by Indigen World's language preservation, cultural learning, storytelling, creator and community themes. These are imaginative artworks, not documentary cultural depictions or approved corporate logos.

## Use

Choose a numbered PNG and set it as your desktop background using your operating system's wallpaper settings. Use Fill for a widescreen display. The compositions leave quiet space for desktop icons.

The built-in image generator returned approximately 16:9 images at 1672 × 941 pixels. These are native generated assets, not 4K exports; a 4K display will enlarge them.

## Collection

- 01–10: landscapes and living heritage
- 11–20: voice, listening and language
- 21–30: material, weaving and craft
- 31–40: stories, learning and memory
- 41–50: community, creators and connected futures

`prompts.json` contains the individual design prompts. Generated with the built-in imagegen tool on October 1, 2026. The first image used the same Savannah Signal concept with a shorter prompt; the recorded prompt describes its intended design.

The palette comes from `packages/design-tokens/colors.json` and the mobile Heritage Green theme. No private corpus, member data or cultural reference photographs were used. External publication and distribution have not been performed. Project asset licensing remains subject to repository licensing policy.
