# Indigen World — 50 project wallpapers

This is the revised collection, created after feedback that the first set relied too heavily on generic landscapes. Every design uses visible project naming and a specific project subject.

## Browse and use

Open `contact-sheet.jpg` to browse, then choose a numbered PNG and set it as your desktop background. Use Fill on widescreen displays. The quiet left side leaves room for desktop icons.

Native image resolution is recorded per file in `manifest.json`; the built-in generator returns approximately 16:9 images at 1672 × 941 pixels. These are not native 4K exports.

## Five project series

| Numbers | Series | Connection to the project |
| --- | --- | --- |
| 01–10 | Kawuri | The actual green, cream, gold and terracotta Weaver bird reference, paired with listening, dictionaries, learning and creation |
| 11–20 | Indigen World | Stylized treatments of the existing website mark: open-bottom roof outline, three internal bars and sun; language, stories and community |
| 21–30 | Project Kassena | Kasem and English lookup, pronunciation, dialect context, source attribution and speaker review |
| 31–40 | TribeStudio | Video timelines, microphones, contributor cards, review and creative tools |
| 41–50 | Beyond the Reef | The project's music-film journey: a wooden outrigger canoe leaving shore, crossing a reef, weathering a storm and moving toward dawn |

Only the ten Kawuri designs feature the bird. The other forty have different subjects.

## Sources and generation

- `apps/mobile/assets/characters/kawuri/community-avatar.png`: actual character reference for the Kawuri series.
- `apps/mobile/assets/characters/kawuri/character.json`: character identity and guide role.
- `apps/website/src/components/BrandMark.tsx`: existing roof/bars/sun mark geometry.
- `apps/website/src/content/kasena.ts`: dictionary programme, dialect context, review and attribution.
- `README.md` and `apps/tribestudio/README.md`: ecosystem and creator/contributor workspace.
- `apps/updates-blog/posts/2026-09-16-beyond-the-reef/post.html`: canoe, reef and journey of the existing music film.
- `packages/design-tokens/colors.json` and the mobile Heritage Green palette: colors.

Generated with the built-in imagegen tool on October 1, 2026. `prompts.json` records each design brief. The first Kawuri dictionary image was generated with the same character reference and an initial standalone version of that brief. These are wallpaper illustrations, not product screenshots or new approved logos; mark treatments may be stylized. No private member data or language corpus was used, and no Kasem expressions were invented.

The previous `indigen-world-50` collection is superseded and is not the requested final set. Public distribution, app integration and Blogger publication have not been performed. Repository licensing policy applies.
